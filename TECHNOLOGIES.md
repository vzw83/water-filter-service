# Журнал технологий проекта

Этот файл фиксирует технологии, которые уже используются в проекте, и служит планом для совместного изучения JavaScript. Обновляем его, когда стек меняется или появляется новая важная техника.

## Стек проекта

| Технология | Версия / состояние | Где используется |
| --- | --- | --- |
| JavaScript | Язык браузерной логики; часть кода пишется на TypeScript | React-компоненты, обработчики формы, выбор и просмотр фотографий |
| TypeScript | `^5` | Типы данных отзывов, компонентов и событий |
| React | `19.3.0` | Компоненты интерфейса, состояние, эффекты и обработчики действий |
| Next.js App Router | `16.4.3` | Маршруты сайта, статическая генерация и сборка |
| CSS Modules | Встроены в проект | Стили отдельных компонентов и адаптивная вёрстка |
| HTML / JSX | JSX внутри TypeScript | Семантическая разметка страниц и форм |
| Node.js и npm | Node.js `22` в GitHub Actions; npm для зависимостей и скриптов | Локальная разработка, установка пакетов, сборка |
| GitHub Actions | Workflow `.github/workflows/deploy.yml` | Сборка и публикация статической версии на GitHub Pages |
| GitHub Pages | Настроено в workflow | Раздача сгенерированных HTML, CSS и JavaScript |
| Supabase JavaScript SDK | `^2.118.0`, добавлен в зависимости | Клиент сайта для входа администратора, базы отзывов и фото |
| Supabase Auth | Код регистрации и входа подготовлен | Аккаунт администратора; клиентам аккаунт не нужен |

| Supabase RPC и PostgreSQL | Функция `admin_visit_stats` во второй миграции | Группировка визитов по дням, неделям, месяцам и годам; запуск доступен администратору |

| CSS Grid | CSS Modules в компоненте аналитики | Столбчатый график посещений с переключением периода |

## Что настроить для запуска

1. Создать проект Supabase.
2. Выполнить SQL-миграцию из `supabase/migrations/`.
3. Заполнить `.env.local` по шаблону `.env.example`.
4. Зарегистрировать владельца на `/reviews/admin` и добавить его в `public.admin_users` по инструкции `SUPABASE_SETUP.md`.
5. Добавить переменные Supabase в Actions secrets GitHub, чтобы опубликованный сайт подключался к базе.

До настройки проекта Supabase формы и админка не подключатся к общей базе. Секретный `service_role` ключ в код сайта добавлять нельзя; сайт использует публичный ключ, а доступы ограничивают политики RLS.

## Темы для изучения JavaScript

Можно проходить постепенно, прямо на примерах этого сайта:

1. Переменные, типы значений, строки, числа и шаблонные строки.
2. Массивы и методы `map`, `filter`, `reduce` — список отзывов и расчёт среднего рейтинга.
3. Объекты и типы данных — структура отзыва.
4. Функции, стрелочные функции и область видимости.
5. События и формы — выбор звёзд, `FormData`, отправка отзыва.
6. Асинхронный JavaScript: `Promise`, `async/await`, обработка ошибок и запросы к Supabase.
7. Состояние и эффекты React: `useState`, `useEffect`, `useMemo`, `useCallback`.
8. Файлы и браузерные API: `File`, `Blob`, загрузка и показ фотографий.
9. Основы безопасности веб-приложений: публичные ключи, серверные секреты, Auth и RLS.
